# `@ecuabyte/cortex-core`

Local-first storage and continuity primitives for Cortex.

The package provides the project-isolated SQLite/FTS5 store, repository-aware task records, evidence capture, handoffs, resume/drift detection, and verification primitives used by the CLI and MCP server.

This is an internal runtime package for Cortex integrations. For installation and end-user usage, start with the [root README](../../README.md) and the [handoff contract](../../docs/architecture/HANDOFF_CONTRACT.md).
